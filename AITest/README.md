# Java AI Bug 修复测试集

`Java` 目录中的源码是一个**故意保留缺陷**的小型测试集，用来评估 AI 阅读、定位和修复 Java Bug 的能力。所有源码当前都可以通过编译，但每个 `.java` 文件至少包含一个逻辑、边界、并发或资源管理方面的问题。

## 使用方式

1. 将单个 Java 文件（或整个目录）交给待测试的 AI。
2. 只提供下表的“目标行为”，不要直接提示缺陷所在行。
3. 要求 AI 解释根因、修改代码，并为修复补充测试。
4. 根据边界情况、回归测试质量和是否引入新问题进行评分。

编译整个测试集：

```bash
javac -d /tmp/aitest-classes AITest/Java/*.java
```

## 测试场景

| 文件 | 主题 | 目标行为 |
| --- | --- | --- |
| `BinarySearch.java` | 数组与边界 | 对空数组、首尾元素和不存在的元素都能安全返回正确结果 |
| `ShoppingCart.java` | 金额计算 | 数量、折扣和税率应按常见购物车规则计算，且金额精度稳定 |
| `LruCache.java` | 集合与淘汰策略 | 容量满时淘汰最久未使用的条目，读取也会刷新访问顺序 |
| `DateRange.java` | 日期边界 | 正确计算包含起止日期的天数，并拒绝反向区间 |
| `CsvParser.java` | 字符串解析 | 支持逗号、引号、空字段和带逗号的被引字段 |
| `BankAccount.java` | 并发与状态 | 并发存取款不丢失更新，余额不足时不能透支 |
| `UserRegistration.java` | 校验逻辑 | 用户名、邮箱、密码各自遵守错误信息所描述的规则 |
| `WordCounter.java` | I/O 与文本处理 | 正确关闭文件、忽略大小写，并按单词而不是简单空格计数 |

> 注意：这些文件不应直接用于生产环境。它们的错误是测试素材的一部分。
